\# 🎾 Tennis Data Analytics Dashboard



\*\*Project 11 | Labmentrix Internship | SportRadar API\*\*



\## 📌 Project Overview

An end-to-end data analytics project that fetches live tennis data from the SportRadar API, stores it in a SQLite database, and visualizes insights through an interactive Streamlit dashboard.



\## 🛠️ Tech Stack

\- \*\*Python\*\* — Data fetching \& processing

\- \*\*SportRadar Tennis API\*\* — Live tennis data

\- \*\*SQLite\*\* — Local database storage

\- \*\*Pandas\*\* — Data manipulation

\- \*\*Streamlit\*\* — Interactive dashboard

\- \*\*Plotly\*\* — Data visualizations



\## 📊 Database Summary

| Table | Records |

|-------|---------|

| competitions | 6,572 |

| categories | 6,572 |

| venues | 3,975 |

| complexes | 764 |

| competitors | 1,000 |

| competitor\_rankings | 1,000 |



\## 🔍 SQL Queries Covered

\- \*\*Competitions:\*\* 7 queries (gender split, categories, types)

\- \*\*Venues \& Complexes:\*\* 7 queries (by country, by complex, timezones)

\- \*\*Rankings:\*\* 6 queries (top players, by country, points distribution)



\## 📱 Dashboard Pages

1\. \*\*Home\*\* — Key metrics + Top 5 countries by venues

2\. \*\*Competitions\*\* — Browse, charts, and search

3\. \*\*Venues \& Complexes\*\* — Country analysis + complex breakdown

4\. \*\*Player Rankings\*\* — Top players, country comparison, points analysis



\## 🚀 How to Run

```bash

pip install -r requirements.txt

streamlit run app.py

```
